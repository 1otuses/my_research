数据按完整 episode 划分训练/验证；滑动窗口在划分后生成。EMA、归一化和任何统计量只依据训练集，滤波状态在 episode 边界重置。预留测试数据或测试环境 seed，不用测试集选择压缩系数和图阈值。

测试执行仅允许本地历史。全局状态、队友真实观察和未来信息可作为训练标签，必须与执行计算图分离。验证时改变其他智能体真实输入，固定 ego 历史，检查 ego 的执行结果是否错误依赖不可访问的信息。

| 对照 | 控制的因素 |
| --- | --- |
| 原 MADiff-D：原采样与 DDIM 5/10/20/50 步 | 采样步数与压缩收益 |
| 普通 latent 自编码器＋diffusion | 表征压缩与特殊损失 |
| 辅助任务预测、再加入 KL | 任务监督与信息压缩 |
| 相近参数量的原空间模型 | 模型容量变化 |
| 稠密图、固定图、随机同密度图、学习图 | 稀疏正则与学习结构的收益 |
| 全频、EMA 趋势＋局部残差 | 频域假设是否成立 |
| CoFlow-D、DoF（后续） | 与近期协调/效率方法比较 |

小规模排错先用 1 个 seed；进入结论阶段至少 3 个 seed，有资源时用 5 个。报告各 seed 原始数据、均值与不确定性估计，固定 seed 不能代替统计可靠性。

主指标为团队回报/胜率及相同硬件下的总决策延迟。延迟包含全部智能体、编码、全部模型调用、CFG、动作解码；记录 batch、dtype、预热、设备同步和计时口径，同时报告中位数与 p95。潜变量维度、每步模型调用次数和规划频率一并记录。

辅助指标包括动作重建误差、潜变量利用率、协同模式失配、图边密度与受控观测扰动下的性能变化。图的稳定或稀疏程度不能独自支持因果识别结论。

混合质量数据记录来源与混合比例，并保持样本预算一致。若要声称轨迹拼接，设计训练数据缺少完整成功路径但包含可组合片段的任务，另外检查转移有效性与组合成功率；普通 mixed 数据回报提高不足以证明拼接。
